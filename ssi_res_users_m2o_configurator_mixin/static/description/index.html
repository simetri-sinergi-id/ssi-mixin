res.users Many2one Configurator Mixin

Description

res.users Many2one Configurator Mixin is part of the @simetri-sinergi-id/ssi-mixin technology suite for Odoo 15. It provides the abstract model mixin.res_users_m2o_configurator, which adds configurable filtering for res.users Many2one fields using a three-strategy pattern: Manual list, Odoo Domain, or Python Code. It integrates with ssi_decorator to optionally inject a ready-made configuration widget into the parent form view.

Key Features

  • Three selection strategies: Manual (explicit user list), Domain (Odoo domain expression), or Python Code (custom script).
  • Auto form injection: Configuration widget is automatically injected into the parent form view via ssi_decorator.
  • Reusable mixin design: Inherit once; get full user-selection configurability in any Odoo model.
  • Open Source: AGPL-3.0 license with community-driven improvements.

Use Cases / Context

This mixin is intended for developers building modules where end-users need to configure which res.users records are selectable in a Many2one field. Common use cases include:

  • Approval workflows: Restrict which users can be selected as approvers.
  • Task assignment: Limit assignable users based on a domain or team membership.
  • Custom dialogs: Dynamically compute available users via Python code at runtime.

Simply inherit mixin.res_users_m2o_configurator and set the two class attributes to enable automatic form injection.

Installation & Usage

  1. Clone branch 15.0 of simetri-sinergi-id/ssi-mixin and add it to your addons_path.
  2. In Odoo Apps, search for res.users Many2one Configurator Mixin and install it.
  3. In your custom model, inherit the mixin and configure the class attributes:
    _inherit = ["mixin.res_users_m2o_configurator"]
    _res_users_m2o_configurator_insert_form_element_ok = True
    _res_users_m2o_configurator_form_xpath = "//field[@name='my_field']"

FAQ

  • Standalone? No — it is a mixin library module. Install it as a dependency of your custom module.
  • Odoo version? Odoo 15.0.
  • Python Code strategy? Write Python code in the user_python_code field. Assign a list of res.users IDs to the variable result.
