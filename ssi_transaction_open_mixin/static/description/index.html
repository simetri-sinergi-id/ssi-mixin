Odoo 15.0

Transaction Mixin
In Progress State

Extends mixin.transaction with an open / in-progress workflow state. Auto-injects the open (start) button and policy fields into form and list views. Provides the action_open lifecycle handler with pre/post check and pre/post action decorator hook points. The active state key is configurable via the _open_state class attribute.

Features
  • Adds open_ok policy field computed automatically for the active user
  • Auto-injects the Start button into the form header with inline visibility expression
  • Auto-injects On Progress state badge decorator (primary colour) on tree views
  • Auto-injects open state filter widget on search views
  • Provides action_open with pre/post check and pre/post action decorator hooks
  • Posts an automatic chatter notification on start action
  • Configurable sequence creation tied to the open state via _create_sequence_state
