Multiple Approval Mixin

Configurable multi-step approval workflow for any transactional document. Define approval sequences, conditions, and approvers using templates with domain or Python code.

Overview

The Multiple Approval Mixin provides a reusable approval framework that can be applied to any Odoo transactional document. Configure approval stages with ordered steps, specify approvers by user or group, and optionally enforce sequential approval.

The mixin automatically injects an approval page into form views and provides action buttons (Approve, Reject, Restart Approval) based on the document's policy state.

Key Features

Template-Based Configuration

Define approval templates per model with ordered detail lines, each specifying approvers and optional conditions.

Sequential or Parallel Approval

Choose between sequential approval (by tier order) or parallel approval where all approvers can act simultaneously.

Flexible Approver Selection

Define approvers by specific users, groups, both, or via Python code for dynamic runtime resolution.

Auto Form View Injection

Automatically injects the approvals page and action buttons into any form view via the decorator mixin.

Condition Evaluation

Templates can be conditionally applied using domain filters or Python expressions with full access to the document context.

Approval Lifecycle Hooks

Pre/post approve and reject hooks allow custom validation and actions at each stage of the approval workflow.

Models

  • approval.template Master template defining the approval sequence for a model. Supports domain and Python computation methods.
  • approval.template_detail One approval step within a template. Defines approvers (users, groups, or Python code) and sequence order.
  • approval.approval Concrete approval record created per step when a document enters the approval flow. Tracks status and approver.
  • mixin.multiple_approval Abstract mixin adding the approval page, approve/reject actions, and automatic form view injection via mixin.decorator.

Installation

Clone the branch 15.0 of the repository https://github.com/simetri-sinergi-id/ssi-mixin, add the path to your Odoo configuration, update the module list, and install Multiple Approval Mixin from the Apps menu.
