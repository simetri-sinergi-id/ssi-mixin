res.partner.bank Many2one Configurator Mixin

Description

res.partner.bank Many2one Configurator Mixin is part of the @simetri-sinergi-id/ssi-mixin technology suite for Odoo 15. It provides an abstract model — mixin.res_partner_bank_m2o_configurator — that adds configurable filtering for res.partner.bank (bank account) Many2one fields using a three-strategy pattern.

The three strategies are:

  • manual — the allowed bank accounts are selected explicitly by the user.
  • domain — a domain expression determines which bank accounts are available.
  • code — arbitrary Python code is evaluated and must assign a list/recordset to result.

Key Features

  • Three-Strategy Filter: Supports manual, domain, and code-based filtering for partner bank accounts.
  • Form View Integration: Optionally inject the configuration widget into any form view via the decorator pattern.
  • Mixin Design: Built to be inherited — no standalone views or menus added.
  • Minimal Footprint: Depends only on base and ssi_decorator.
  • Open Source: AGPL-3.0 license with community-driven improvements.

Use Cases / Context

This mixin is ideal for developers who need runtime-configurable bank account filtering:

  • Payment Documents: Restrict selectable bank accounts on payment forms based on partner or company rules.
  • Vendor Bills / Expenses: Dynamically filter bank accounts depending on the vendor or business unit.
  • Custom Workflows: Any document model that requires a filtered res.partner.bank Many2one field.
  • Configuration Records: Manage allowed bank accounts per configuration template without modifying source code.

Simply set _inherit = ["mixin.res_partner_bank_m2o_configurator"] in your model and set _res_partner_bank_m2o_configurator_insert_form_element_ok = True to enable the configuration widget.

Installation & Usage

  1. Clone branch 15.0 of the repository: https://github.com/simetri-sinergi-id/ssi-mixin
  2. Add the path to this repository in your Odoo configuration (addons-path).
  3. Update the module list (ensure you are in developer mode).
  4. Go to Apps → Apps → Main Apps, search for res.partner.bank Many2one Configurator Mixin, and install.
  5. In your custom model:
    _inherit = ["mixin.res_partner_bank_m2o_configurator"]
  6. Set _res_partner_bank_m2o_configurator_insert_form_element_ok = True and configure _res_partner_bank_m2o_configurator_form_xpath to inject the widget into your form view.
