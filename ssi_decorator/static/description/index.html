SSI - Decorator

Description

SSI - Decorator is a utility module for Odoo that provides Python decorator patterns for business process hooks (confirm, approve, reject, open, ready, queue to done, etc). It enables modular, extensible, and readable business logic in Odoo models.

Key Features

  • Reusable Python decorators for Odoo business process hooks.
  • Separation of concerns for pre/post action and check logic.
  • Easy to extend and maintain business logic.
  • Open Source: AGPL-3.0 license, community-driven.

Use Cases / Context

  • Standardize approval, confirmation, and rejection logic in custom modules.
  • Enable modular hooks for business process transitions.
  • Reduce code duplication in workflow logic.

Installation & Usage

  1. Add ssi_decorator to your Odoo addons path.
  2. Install via Odoo Apps menu.
  3. Import and use decorators in your custom models for business process hooks.

FAQ

  • Standalone? Yes, but intended to be used as a utility for other modules.
  • Odoo Version? Odoo 18.0 or above.
