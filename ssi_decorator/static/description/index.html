SSI - Decorator

Description

SSI - Decorator is a foundational utility module in the @simetri-sinergi-id/ssi-mixin technology suite for Odoo 15. It provides two complementary tools: a view-decoration framework and a collection of Python method decorators for declarative business-action hooks.

Any model that inherits from mixin.decorator can define methods marked with the SSI decorator tags to programmatically inject XML fragments into views at runtime, without writing XML inherit records:

  • _insert_on_form_view — called to modify the form-view XML.
  • _insert_on_tree_view — called to modify the list-view XML.
  • _insert_on_search_view — called to modify the search-view XML.

Additionally, ssi_decorator.py exports a full set of Python decorator factories for hooking into transaction lifecycle actions (confirm, approve, reject, open, ready, done, cancel, restart, terminate, win, lost, etc.).

Key Features

  • Runtime View Injection: Inject XML fragments into form, list, and search views via Python methods — no XML inherit records needed.
  • Declarative Discovery: The mixin auto-discovers decorated methods via introspection during fields_view_get and calls them in sequence.
  • QWeb Fragment Support: _add_view_element renders a QWeb template and inserts it before, after, or inside a target xpath node.
  • Transaction Hook Decorators: A full library of pre_*/post_* decorator factories for all standard transaction lifecycle stages.
  • Zero Dependencies: Depends only on base — suitable as a lightweight foundation for all other SSI mixin modules.
  • Open Source: AGPL-3.0 license with community-driven improvements.

Use Cases / Context

Use this module as a building block for any SSI mixin that needs to dynamically extend views or hook into action pipelines:

  • Dynamic Field Injection: Add fields to a form view from a mixin without touching the base module's XML.
  • Conditional Button Rendering: Insert action buttons into list or form views based on model-level logic.
  • Pre/Post Action Hooks: Run validation or side-effect logic before and after confirm, approve, cancel, and other business actions.
  • Cross-Module View Extension: Extend views from other modules entirely in Python — useful for mixin-based architectures.

Inherit mixin.decorator in your model and mark methods with the appropriate decorator tags, or import the hook decorators from ssi_decorator directly.

Installation & Usage

  1. Clone branch 15.0 of the repository: https://github.com/simetri-sinergi-id/ssi-mixin
  2. Add the path to this repository in your Odoo configuration (addons-path).
  3. Update the module list (ensure you are in developer mode).
  4. Go to Apps → Apps → Main Apps, search for SSI - Decorator, and install.
  5. In your custom model:
    _inherit = ["mixin.decorator"]
  6. Define methods and mark them with @insert_on_form_view(), @insert_on_tree_view(), or @insert_on_search_view() from ssi_decorator.

FAQ

  • Standalone? No — it is a mixin foundation. Install it as a dependency of your custom module.
  • Odoo Version? Odoo 15.0.
  • Can I use the hook decorators without inheriting mixin.decorator? Yes — import from odoo.addons.ssi_decorator import ssi_decorator and use the decorator factories directly in any model.
  • What order are decorated methods called in? They are discovered via inspect.getmembers and called in the order returned, which is alphabetical by method name.
  • Contribute? Fork, branch, and submit a pull request on GitHub.
