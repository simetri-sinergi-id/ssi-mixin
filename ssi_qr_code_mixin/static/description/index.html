QR Code Mixin

Description

QR Code Mixin is a core mixin module in the simetri-sinergi-id/ssi-mixin technology suite for Odoo 15. It provides a reusable abstract model — mixin.qr_code — that adds a computed QR-code image field to any Odoo model.

Any model inheriting from mixin.qr_code automatically gains a qr_image Binary field (PNG encoded as Base64), configurable content strategy per model via ir.model, and optional automatic injection of a QR Code tab into the form view.

Key Features

  • Computed QR Image: Adds a qr_image Binary field computed on-the-fly — no database storage required.
  • Flexible Content Strategy: Each model can use the default web URL or define custom Python code to generate QR content via ir.model configuration.
  • Auto View Injection: Optionally injects a QR Code page tab into form views by setting _qr_code_create_page = True.
  • Mixin Design: Built to be inherited — zero standalone functionality, maximum reusability.
  • Open Source: AGPL-3.0 license with community-driven improvements.

Use Cases / Context

This mixin is ideal for developers who need to attach a scannable QR code to Odoo records. Common use cases include:

  • Document Traceability: Attach a scannable QR code to invoices, sales orders, or HR contracts that deep-links to the Odoo record.
  • Asset Tagging: Print QR labels for fixed assets pointing directly to the asset record.
  • Custom QR Content: Use Python code via ir.model to embed custom data such as serial numbers or barcodes.
  • Mobile Access: Allow warehouse or field staff to scan a QR code and open the record on a mobile browser.

Installation & Usage

  1. Clone the repository: git clone https://github.com/simetri-sinergi-id/ssi-mixin -b 15.0
  2. Install the Python dependency: pip install qrcode
  3. Add to addons path and install QR Code Mixin from the Odoo Apps menu.
  4. Inherit in your module: 
    class MyModel(models.Model):
    _name = "my.model"
    _inherit = ["my.model", "mixin.qr_code"]
    _qr_code_create_page = True  # auto-inject QR Code tab
  5. Customise QR content (optional): go to Settings → Technical → Models, open the model, select the QR Content tab, disable Use Standard Content, and write Python code assigning the desired string to result.

FAQ

  • Is this module standalone? No. It is a mixin foundation intended to be inherited by other modules.
  • What is the default QR content? The full web URL of the record (web.base.url + /web?#id=...).
  • Odoo Version? Odoo 15.0.
  • Contribute? Fork, branch, and submit a pull request on GitHub.
