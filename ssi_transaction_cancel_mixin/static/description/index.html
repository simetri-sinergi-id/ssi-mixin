Transaction Mixin - Cancel State 15.0

PT. Simetri Sinergi Indonesia — AGPL-3

Extends mixin.transaction with a cancel lifecycle state, cancellation reason tracking, and policy-based access control.

Models

  • base.cancel_reason — Master-data model for cancellation reasons (name, code, optional global_use flag).
  • ir.model extension — Links cancellation reasons to specific models via cancel_reason_ids.
  • mixin.transaction_cancel — Adds cancel_ok policy field, cancel_reason_id, action_cancel, and restart support to any inheriting transaction document.

Features

  • Policy-controlled cancel button auto-injected into form views.
  • Cancel reason selection wizard (base.select_cancel_reason).
  • Pre/post cancel check and action hooks via ssi_decorator.
  • Cancel state badge auto-injected into tree views.
  • Cancel filter auto-injected into search views.

Installation

  • Clone branch 15.0 of https://github.com/simetri-sinergi-id/ssi-mixin
  • Add the path to your Odoo addons_path configuration.
  • Update the module list and install Transaction Mixin - Cancel State.
