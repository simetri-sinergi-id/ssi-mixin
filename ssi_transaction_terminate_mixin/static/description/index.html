Transaction Mixin - Terminate State 15.0

PT. Simetri Sinergi Indonesia — AGPL-3

Extends mixin.transaction with a terminate lifecycle state for premature closure — distinct from cancellation — with reason tracking and policy-based access control.

Models

  • base.terminate_reason — Master-data model for termination reasons (name, code, optional global_use flag).
  • ir.model extension — Links termination reasons to specific models via terminate_reason_ids.
  • mixin.transaction_terminate — Adds terminate_ok policy field, terminate_reason_id, and action_terminate lifecycle handler to any inheriting transaction document.

Features

  • Policy-controlled terminate button auto-injected into form views.
  • Terminate reason selection wizard (base.select_terminate_reason).
  • Pre/post terminate check and action hooks via ssi_decorator.
  • Terminate state badge auto-injected into tree views.
  • Terminate filter auto-injected into search views.

Installation

  • Clone branch 15.0 of https://github.com/simetri-sinergi-id/ssi-mixin
  • Add the path to your Odoo addons_path configuration.
  • Update the module list and install Transaction Mixin - Terminate State.
