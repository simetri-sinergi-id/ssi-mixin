Related Attachment Mixin

Description

Related Attachment Mixin is a core mixin module in the @simetri-sinergi-id/ssi-mixin technology suite for Odoo 15. It provides a structured required-attachment framework that can be mixed into any Odoo model to enforce document attachment requirements, verification workflows, and categorised attachment tracking.

Key models provided:

  • attachment.related_attachment_category — groups attachment requirements by category.
  • attachment.related_attachment_template — defines which attachments are required for a given model with ordered detail lines.
  • attachment.related_attachment_template_detail — one requirement entry with optional Python condition, category, and verification rules.
  • attachment.related_attachment — concrete attachment record linked to a document (via model + res_id) and a template detail line.
  • mixin.related_attachment — abstract mixin that injects the attachment page into any form view.

Key Features

  • Attachment Templates: Define required attachments per model using ordered detail lines with optional Python conditions.
  • Attachment Categories: Group requirements into named categories for clear display organisation on the document form.
  • Flexible Verification: Supports user-based, group-based, combined, or Python-code-based verification methods per requirement.
  • Mixin Design: Inherit mixin.related_attachment to automatically inject the attachment page into any form view.
  • Import Wizard: Upload new files or select existing ir.attachment records via a dedicated wizard.
  • Trigger Fields: Specify model fields on ir.model that trigger re-evaluation of attachment requirements.
  • Status Tracking: Computes counts (all / verified / unverified) and an overall status (Not Needed / In Progress / Done).
  • Open Source: AGPL-3.0 license with community-driven improvements.

Use Cases / Context

This mixin is ideal for any workflow that requires structured, verifiable document attachments:

  • Procurement: Enforce mandatory supporting documents (e.g. quotations, approval memos) for purchase orders before they are confirmed.
  • HR Onboarding: Require employees to attach identity documents and contracts before onboarding is marked complete.
  • Finance: Ensure all invoices have valid supporting evidence (receipts, PO references) before approval.
  • Compliance: Track and verify regulatory documents per transaction type.
  • Custom Workflows: Add structured attachment requirements to any custom module by simply inheriting the mixin.

Installation & Usage

  1. Clone branch 15.0 of the repository: https://github.com/simetri-sinergi-id/ssi-mixin
  2. Add the path to this repository in your Odoo configuration (addons-path).
  3. Update the module list (ensure you are in developer mode).
  4. Go to Apps → Apps → Main Apps, search for Related Attachment Mixin, and install.
  5. Go to Related Attachment → Templates and create a template for the target model.
  6. Add detail lines specifying the required categories and verifiers.
  7. In your custom model:
    _inherit = ["mixin.related_attachment"]
    _related_attachment_create_page = True
  8. On the document form, use the Related Attachment page to manage and verify attachments.

FAQ

  • Standalone? No — it is a mixin foundation. Install it as a dependency of your custom module.
  • Odoo Version? Odoo 15.0.
  • Can I have multiple templates per model? Yes — templates are filtered by model name and the user selects the applicable template on the document.
  • How does verification work? Each template detail line defines allowed verifiers (users, groups, or Python-evaluated). Only those users see the Verify button for that attachment.
