===========================
Test: Master Data Mixin
===========================

Modul ini adalah modul pengujian untuk ``ssi_master_data_mixin``.
Menyediakan objek sederhana ``test_ssi_master_data`` yang mewarisi
``mixin.master_data`` guna memverifikasi bahwa mixin berfungsi dengan benar.
