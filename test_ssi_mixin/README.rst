===============
Test SSI Mixin
===============

Test module for the SSI Mixin suite. Provides a simple master data model
``test.mixin.type`` to verify that ``mixin.master_data`` works correctly.


Bug Tracker
===========

Bugs are tracked on `GitHub Issues
<https://github.com/open-synergy/ssi-mixin/issues>`_. In case of trouble, please
check there if your issue has already been reported. If you spotted it first,
help us smash it by providing detailed and welcomed feedback.
