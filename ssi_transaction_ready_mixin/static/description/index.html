Transaction Mixin - Ready to Process State

Description

Transaction Mixin - Ready to Process State is part of the @simetri-sinergi-id/ssi-mixin technology suite for Odoo 15. It extends mixin.transaction with a ready intermediate state that sits between draft/confirm and in-progress.

Any model that inherits from mixin.transaction_ready automatically gains:

  • A ready_ok policy field computed automatically via _compute_policy.
  • Auto-injection of the Stage button into the form header, gated by the ready_ok policy field.
  • Auto-injection of the Ready to Process filter on search views.
  • Auto-injection of a state badge decorator on tree/list views.
  • The action_ready lifecycle handler with configurable pre/post check and pre/post action decorator hooks.
  • Automatic chatter notification posted on staging.

Key Features

  • Ready State Policy: ready_ok field computed automatically; controls button visibility.
  • Auto View Injection: Stage button, policy fields, tree badge decorator, and search filter injected automatically — no manual view changes needed.
  • Lifecycle Hooks: _pre_ready_check, _post_ready_check, _pre_ready_action, _post_ready_action decorator hooks.
  • Policy Guard: _check_ready_policy raises a descriptive UserError if staging is not permitted.
  • Configurable State: Override _ready_state to map to a custom state value.
  • Chatter Integration: Automatic notification message posted to the record's chatter on every staging action.
  • Open Source: AGPL-3.0 license with community-driven improvements.

Use Cases / Context

Use this mixin when a transaction needs an explicit ready gate before it can be processed:

  • Service Orders: Require a technician to confirm readiness before work begins.
  • Manufacturing Orders: Validate materials and resources are staged before production starts.
  • Appointment Scheduling: Mark an appointment as ready once all prerequisites are met.
  • Project Tasks: Gate task execution behind a ready-to-start check.
  • Any Multi-Stage Transaction: Any workflow that benefits from a distinct "staged/ready" checkpoint.

Simply set _inherit = ["mixin.transaction_ready"] on your model and the state, button, and filters are wired up automatically.

Installation & Usage

  1. Clone branch 15.0 of the repository: https://github.com/simetri-sinergi-id/ssi-mixin
  2. Add the path to this repository in your Odoo configuration (addons-path).
  3. Update the module list (ensure you are in developer mode).
  4. Go to Apps → Apps → Main Apps, search for Transaction Mixin - Ready to Process State, and install.
  5. In your custom model:
    _inherit = ["mixin.transaction_ready"]
  6. Optionally override _ready_state to use a custom state value other than "ready".

FAQ

  • Standalone? No — it is a mixin that requires ssi_transaction_mixin as a dependency.
  • Odoo Version? Odoo 15.0.
  • Can I bypass the policy check? Yes — pass bypass_policy_check=True in the context.
  • Can I disable the auto-injected button or filter? Yes — set _automatically_insert_ready_button = False or _automatically_insert_ready_filter = False on your model.
  • Contribute? Fork, branch, and submit a pull request on GitHub.
