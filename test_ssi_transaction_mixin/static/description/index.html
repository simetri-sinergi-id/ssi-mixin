Test Module: Transaction Mixin

Modul pengujian workflow transaksi untuk memastikan perilaku mixin SSI konsisten setelah migrasi ke Odoo 15.0.

Description

Test Module: Transaction Mixin digunakan untuk menguji rangkaian proses transaksi berbasis mixin, termasuk transisi status, approval, sequence, dan hook decorator pre/post.

Key Features

  • Pengujian status transaksi: draft, confirm, open, done, cancel, terminate.
  • Pengujian decorator check dan action pada setiap tahapan workflow.
  • Integrasi dengan policy template, approval template, dan sequence template.
  • Contoh relasi header-detail transaksi untuk skenario uji yang realistis.

Use Cases / Context

  • Regression test saat ada perubahan pada modul mixin transaksi SSI.
  • Referensi implementasi modul transaksi berbasis inheritance mixin.
  • Validasi hasil migrasi modul custom dari 14.0 ke 15.0.

Installation

  1. Clone branch 15.0 dari repository ssi-mixin.
  2. Tambahkan path repository ke konfigurasi addons-path Odoo.
  3. Update app list dalam mode developer.
  4. Install modul test_ssi_transaction_mixin dari menu Apps.

Installation & Usage

  1. Pastikan semua dependency transaksi mixin sudah terpasang.
  2. Buat transaksi uji melalui menu Test Transaction Mixin.
  3. Jalankan action confirm/open/done/cancel/terminate sesuai skenario.
  4. Verifikasi field check/action terisi sesuai hook decorator.

FAQ

  • Apakah modul ini untuk produksi? Tidak, modul ini untuk validasi/testing.
  • Versi Odoo? Ditujukan untuk Odoo 15.0.
  • Bagaimana melaporkan masalah? Gunakan GitHub Issues.
